# Simple Calculator

A responsive calculator built using **HTML, CSS, and JavaScript**.

## Features

- Clean modern UI
- Responsive layout
- Basic arithmetic operations (+, −, ×, ÷)
- AC (Clear All) and DEL functionality
- Button click animation

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
